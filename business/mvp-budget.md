# MVP budget — pilot-ready validation

## Objective

Estimate the budget required to move from the current software proof of concept to a pilot-ready validation package.

This is a first approximation for funding conversations, not a supplier quote.

## Scenario A — Lean validation package

Goal: validate legal/commercial feasibility before building hardware.

| Item | Estimated cost |
|---|---:|
| Legal consultation: tobacco retail + vending | €2,000–€5,000 |
| RGPD/DPIA initial review | €2,000–€4,000 |
| Product/business documentation | €0–€2,000 |
| Customer discovery and travel | €500–€1,500 |
| Demo video / visual material | €0–€1,500 |
| Contingency | €1,000–€2,000 |
| **Total** | **€5,500–€16,000** |

Recommended if the priority is to avoid spending on hardware before regulatory feasibility is clearer.

## Scenario B — Software MVP + hardware bench prototype

Goal: create a demonstrable prototype without real commercial deployment.

| Item | Estimated cost |
|---|---:|
| Legal + RGPD review | €4,000–€9,000 |
| NFC reader/dev kit | €100–€500 |
| Camera/depth camera | €200–€800 |
| Touchscreen terminal / mini PC | €800–€2,500 |
| Basic enclosure/mock kiosk | €1,000–€5,000 |
| Biometric SDK evaluation/licensing | €2,000–€10,000 |
| Software integration work | €8,000–€25,000 |
| Security review / pentest light | €3,000–€8,000 |
| Documentation and pilot protocol | €2,000–€5,000 |
| Contingency | €3,000–€7,000 |
| **Total** | **€24,100–€72,800** |

Recommended if a hardware or vending partner is available.

## Scenario C — Controlled commercial pilot

Goal: pilot inside a partner environment, still under strict legal and operational controls.

| Item | Estimated cost |
|---|---:|
| Full legal/regulatory counsel | €8,000–€20,000 |
| DPIA + privacy/legal documentation | €5,000–€12,000 |
| Industrial kiosk hardware | €8,000–€25,000 |
| Hardware integration | €10,000–€30,000 |
| Production-grade biometric vendor | €10,000–€40,000 |
| Backend/dashboard MVP | €15,000–€45,000 |
| Security testing | €8,000–€20,000 |
| Pilot operations/support | €5,000–€15,000 |
| Insurance/contingency | €5,000–€15,000 |
| **Total** | **€74,000–€222,000** |

Recommended only after legal feasibility and customer demand are validated.

## Funding strategy

### Phase 1 — Validation funding

Target: €10k–€20k.

Use for:

- Legal feasibility.
- DPIA outline.
- Customer interviews.
- Better pitch material.
- Partner search.

Best sources:

- Personal/bootstrap.
- Small grants.
- Women entrepreneur programs.
- Accelerator pre-seed support.

### Phase 2 — MVP funding

Target: €50k–€100k.

Use for:

- Hardware bench prototype.
- Biometric SDK evaluation.
- Security review.
- Pilot agreement.

Best sources:

- ENISA Emprendedoras Digitales.
- Hardware partner co-development.
- Business angel with regulated-retail background.
- Regional innovation grants.

### Phase 3 — Pilot/scale funding

Target: €150k–€300k+.

Use for:

- Production-grade integrations.
- Legal/regulatory process.
- Pilot deployment.
- Sales and compliance dashboard.

Best sources:

- ENISA Growth / startup lines.
- CDTI/NEOTEC if technological innovation is strengthened.
- Strategic industrial partner.
- Venture capital only after validation.

## Recommendation

Do **not** raise money for full hardware immediately.

Best next step:

1. Build a strong validation package.
2. Secure 10–20 interviews.
3. Get legal/regulatory opinion.
4. Find a hardware/vending partner.
5. Then seek €50k–€100k for MVP.
