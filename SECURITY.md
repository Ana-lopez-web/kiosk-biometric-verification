# Security policy

## Supported versions

This is a portfolio/proof-of-concept project and is not deployed as a production service. Security fixes are considered for the latest `main` branch.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub Issues.

Use the project security contact instead:

- `security@example.com` — replace with the project security email before publication.

When reporting, include:

- Affected file, component or workflow.
- Clear reproduction steps.
- Potential impact.
- Any suggested mitigation, if available.

I will acknowledge valid reports as soon as practical and avoid public disclosure until a fix or mitigation is available.

## Scope notes

The current repository contains mockable interfaces and a simulated verification workflow. It does **not** include production NFC integration, live biometric SDK credentials, payment terminals, deployed infrastructure or real personal data.
